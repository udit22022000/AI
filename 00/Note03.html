RUNNING PYTHON

Running Python and keeping projects tidy

There are two ways to use Python. The REPL (type python3 in a terminal) runs each line as soon as you press Enter, which is perfect for experiments: you'll see >>> as the prompt. A script is a .py file you run in one go. Windows users usually type py instead of python3.

CommandWhat it does
python3Open the interactive REPL. Leave with exit() or Ctrl-D.
python3 script.pyRun a file from top to bottom.
python3 -i script.pyRun a file, then stay in the REPL with its variables, great for poking at results.
python3 -m venv .venv-m runs a module as a program. Here: create a virtual environment.
python3 -c "print(2 ** 10)"Run a one-line program.
python3 --versionCheck which version you have. This guide assumes 3.12 or newer.

Virtual environments: one box of packages per project

Packages are extra libraries you install, such as requests or pandas. If every project installed into the same place, upgrading a package for one project could break another. A virtual environment (venv) is a folder holding a private copy of Python and its own packages for one project. Use one for every project.

  1. Create it once inside your project folder: python3 -m venv .venv
  2. Activate it every time you open a new terminal: source .venv/bin/activate on macOS/Linux, .venv\Scripts\activate on Windows. Your prompt now starts with (.venv).
  3. Install packages into it: pip install requests
  4. Record what you installed so others can recreate it: pip freeze > requirements.txt, and later pip install -r requirements.txt
  5. Leave it with deactivate. Never commit the .venv folder to git; the requirements file is enough.
Faster option: uv is a modern tool that does the same job much faster: uv venv, uv pip install requests, or simply uv run script.py.
Every script's skeleton 
def main():
    name = input("Your name: ")
    print(f"Hello, {name}!")

if __name__ == "__main__":   # True only when this file is run directly
    main()

Putting your code in a main() function and calling it under if __name__ == "__main__": means the file can be run as a program and imported by other files without running anything.

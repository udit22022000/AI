SETS

Sets: unique items and fast membership

A set is an unordered collection with no duplicates. Adding something that's already there does nothing. Sets answer "is x in here?" instantly, using the same hash-table trick as dicts, and support the set maths you may remember from school.

tags = {"python", "data", "python"}
print(len(tags))                  # 2           the duplicate disappeared
print("data" in tags)             # True        instant, even for millions of items
tags.add("ml")
tags.discard("nope")              # discard: no error if missing
tags.remove("nope")               # KeyError: 'nope'   remove: error if missing
empty = set()                     # NOT {} — that's an empty dict!
print(set([3, 1, 3, 2]))          # {1, 2, 3}

Set operations

Here a = {1, 2, 3, 4} and b = {3, 4, 5, 6}. Click an operation to see which part of the diagram it keeps:

emails = ["a@x.com", "b@x.com", "a@x.com"]
print(len(set(emails)))         # 2   how many unique?
# remove duplicates but keep the order:
print(list(dict.fromkeys(emails)))   # ['a@x.com', 'b@x.com']
banned = {"spam", "scam"}
words = ["hi", "spam", "yo"]
print([w for w in words if w not in banned])   # ['hi', 'yo']
Sets have no order and no indexes: tags[0] is an error, and the printed order may differ from the order you added items. Need an immutable set (e.g. as a dict key)? Use frozenset({1, 2}). Test subsets with {1, 2} <= a.

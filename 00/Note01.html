Watch the virtual machine work

Python first translates your code into bytecode, a list of tiny instructions, and then a virtual machine runs them one at a time. The animation below runs a small function, total([10, 20], 0.5), exactly as Python 3.12 does. You don't need to understand def and for yet; just watch the values move. The four panels are:

Sourcethe line of your code being run
Bytecodethe real instructions Python made from it
Local variablesthe function's own labelled slots: prices, tax, s, p
Scratch pilea stack of values. Instructions put values on top, and + takes the top two off and puts the answer back

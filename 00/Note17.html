SCOPE

Scope: where a variable can be seen

A variable's scope is the part of the program where its name exists. A variable created inside a function is local: it exists only while that function runs and can't be seen from outside. When Python meets a name, it searches four places in a fixed order, remembered as LEGB:

  1. Local: names created inside the current function.
  2. Enclosing: names in any function that contains this one (for nested functions).
  3. Global: names created at the top level of the current file (module).
  4. Built-in: names Python provides everywhere, such as len, print and range.

Python stops at the first place the name is found. Click a name used inside inner() to watch the search:

x = "global x"

def outer():
    y = "enclosing y"
    def inner():
        z = "local z"
        print(z, y, x, len)      # where does each name come from?
    inner()

outer()     # local z enclosing y global x <built-in function len>
What's happening

Result
Assigning makes a name local everywhere in the function 
counter = 0
def bump():
    counter += 1
bump()
# UnboundLocalError:
#   cannot access local variable
#   'counter' where it is not
#   associated with a value
global lets a function change a top-level name 
counter = 0
def bump():
    global counter  # the global one
    counter += 1
bump(); bump()
print(counter)      # 2
Local variables vanish when the function ends 
def show():
    total = 10
    return total

show()
print(total)
# NameError: name 'total'
#   is not defined
Reading a global inside a function is fine. Changing one needs global, but try to avoid it: functions that quietly change globals are hard to test and debug. Pass values in as parameters and return results instead. To change a variable of an enclosing function, use nonlocal (see Closures below).

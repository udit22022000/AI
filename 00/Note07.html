CONTROL FLOW

Making decisions and repeating work

By default Python runs lines top to bottom. Control flow changes that: if picks which lines run, for and while repeat lines, and match picks a branch based on the shape of some data.

if / elif / else

Python checks each condition from top to bottom and runs the first block whose condition is true, then skips the rest. elif ("else if") and else are optional. Pick a score to see which lines run:

score = 72
status = "pass" if score >= 50 else "fail"   # conditional expression: a one-line if/else
print(status)                                # pass

for loops: do something with each item

A for loop takes each item from a collection in turn, assigns it to the loop variable, and runs the indented block. It works on anything you can step through: lists, strings, dicts, files, ranges…

for ch in "abc":
    print(ch, end=" ")            # a b c
print()
for i in range(3):                # range(3) gives 0, 1, 2
    print(i, end=" ")             # 0 1 2
print()
print(list(range(2, 10, 3)))      # [2, 5, 8]    start, stop, step
print(list(range(5, 0, -1)))      # [5, 4, 3, 2, 1]
fruits = ["apple", "banana", "cherry"]
prices = [1.2, 0.5, 3.0]
# enumerate: position AND item
for i, fruit in enumerate(fruits, start=1):
    print(i, fruit)        # 1 apple / 2 banana / 3 cherry
# zip: walk two lists side by side
for fruit, price in zip(fruits, prices):
    print(fruit, price)    # apple 1.2 / banana 0.5 / cherry 3.0
for fruit in reversed(fruits): ...         # backwards
for fruit in sorted(fruits, key=len): ...  # sorted
Don't write for i in range(len(fruits)) just to get each item. Loop over the list directly, and use enumerate when you also need the position.

break, continue and while

continue skips the rest of this round and moves to the next item. break leaves the loop completely. Step through to watch both:

while: repeat as long as a condition is true 
count = 3
while count > 0:
    print(count)
    count -= 1        # without this, the loop never ends!
print("lift off")     # 3 / 2 / 1 / lift off

while True:           # loop "forever"…
    answer = input("Type q to quit: ")
    if answer == "q":
        break         # …until break
Loop else: "no break happened" 
def first_factor(x):
    for d in range(2, x):
        if x % d == 0:
            return d
    else:                 # runs only if the loop
        return None       # finished without break/return

print(first_factor(91), first_factor(13))   # 7 None

Use for when you know what to loop over; use while when you loop until something happens.

match / case: branch on the shape of data

match (Python 3.10+) compares a value against a series of patterns and runs the first one that fits. Unlike a chain of ifs, a pattern can also pull values out: case ["go", direction] matches any two-item list starting with "go" and puts the second item into direction.

def describe(event):
    match event:
        case {"type": "click", "pos": (x, y)}:   # dict pattern, unpacks the tuple
            return f"click at {x},{y}"
        case int() | float() as n:               # match by type, name the value
            return f"number {n}"
        case _:
            return "other"

print(describe({"type": "click", "pos": (3, 4)}))   # click at 3,4
print(describe(2.5))                                # number 2.5
Gotcha: a bare name in a pattern captures anything; it doesn't compare. case limit: matches every value and overwrites limit. Compare against literals (case 0:) or dotted names (case Color.RED:).
The walrus operator := (assign inside an expression) 
data = [5, 12, 7, 20]
if (n := len(data)) > 3:          # compute once, use twice
    print(f"{n} items")           # 4 items

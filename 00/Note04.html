SYNTAX ESSENTIALS

The grammar of Python

Python reads like structured English. Two rules surprise newcomers: indentation is part of the syntax (it's how Python knows which lines belong to an if, a loop or a function), and a line ending in a colon : always starts a new indented block.

temperature = 31
if temperature > 30:          # the colon opens a block
    print("Hot!")             # indented 4 spaces: inside the if
    print("Drink water.")     # still inside
print("Done.")                # back at the left edge: always runs
Always use 4 spaces per level (your editor does this when you press Tab). Mixing tabs and spaces, or indenting one line by 3 and the next by 4, causes IndentationError. There are no curly braces or end keywords: the indentation is the structure.

Variables, names and assignment

You create a variable simply by assigning to it with =; there's no declaration step. = means "make this name point at this value", not "is equal" (that's ==).

# a comment: Python ignores everything after #
x = 10                    # create a variable
first_name = "Ada"        # snake_case for variables and functions
MAX_RETRIES = 3           # UPPER_CASE signals "constant" (by convention only)
a, b = 1, 2               # assign several at once
a, b = b, a               # swap, no temporary variable needed
print(a, b)               # 2 1
x += 5                    # same as x = x + 5   (also -= *= /= //= %= **=)
print(x)                  # 15
total = (1 + 2 +
         3 + 4)           # a long line can continue inside ( ) [ ] { }
print(total)              # 10

Names can contain letters, digits and underscores, but can't start with a digit, and they're case-sensitive (Total and total are different). Avoid built-in names such as list, str, sum or input: list = [1, 2] works, but hides the real list() for the rest of your file.

Printing and reading input

print("a", "b", "c")            # a b c      items separated by spaces
print("a", "b", sep="-")        # a-b        choose the separator
print("same line", end="")      # end="": don't start a new line
print()                         # an empty line
x = 15
print(f"{x=}")                  # x=15       quick debugging
name = input("Your name: ")     # waits for the user to type
age = int(input("Age: "))       # input() ALWAYS returns a string,
                                # so convert it to do maths
print(f"{name} will be {age + 1} next year")

Asking Python about things

These built-in functions let you inspect any value, and are your best friends in the REPL:

print(type(3.0))                  # <class 'float'>
print(isinstance(3, (int, float)))  # True   one of these types?
print(len("hello"))               # 5      how many characters?
print(round(3.14159, 2))          # 3.14
print(max(4, 9, 2), min([4, 9, 2]), sum([4, 9, 2]))   # 9 2 15
# dir(str)          lists every method a str has
# help(str.split)   shows the documentation (press q to leave)
